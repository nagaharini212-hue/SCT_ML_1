# House Price Prediction using Linear Regression

## Objective

To build a Linear Regression model that predicts house prices based on:

* Area
* Bedrooms
* Bathrooms

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Google Colab

## Result

The Linear Regression model successfully predicted house prices using housing features. The model was trained and evaluated using machine learning techniques, and the predictions were visualized using graphs.
